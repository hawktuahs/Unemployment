API Documentation

The following API endpoints are available:

Employees

  • GET /api/employees - Get all employees
  • GET /api/employees/{id} - Get employee by ID
  • POST /api/employees - Create a new employee
  • PUT /api/employees/{id} - Update an employee
  • DELETE /api/employees/{id} - Delete an employee

Approval Requests

  • GET /api/approvals - Get all approval requests
  • GET /api/approvals/{id} - Get approval request by ID
  • POST /api/approvals - Create a new approval request
  • PUT /api/approvals/{id} - Update an approval request
  • DELETE /api/approvals/{id} - Delete an approval request
