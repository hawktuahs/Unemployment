Approval Hierarchy System - API Examples

API Examples

This page provides examples of how to use the REST API endpoints of the Approval Hierarchy System.

Back to Home

Employee API

GET /api/employees

Get all employees in the system.

Example Request:

curl -X GET http://localhost:8080/api/employees

Example Response:

[
  {
    "id": 1,
    "name": "John Doe",
    "email": "john.doe@example.com",
    "position": "Manager",
    "available": true,
    "manager": null
  },
  {
    "id": 2,
    "name": "Jane Smith",
    "email": "jane.smith@example.com",
    "position": "Team Lead",
    "available": true,
    "manager": {
      "id": 1,
      "name": "John Doe"
    }
  }
]

POST /api/employees

Create a new employee.

Example Request:

curl -X POST http://localhost:8080/api/employees \
-H "Content-Type: application/json" \
-d '{
  "name": "Alice Johnson",
  "email": "alice.johnson@example.com",
  "position": "Developer",
  "available": true,
  "manager": {
    "id": 2
  }
}'

Example Response:

{
  "id": 3,
  "name": "Alice Johnson",
  "email": "alice.johnson@example.com",
  "position": "Developer",
  "available": true,
  "manager": {
    "id": 2,
    "name": "Jane Smith"
  }
}

Approval API

GET /api/approvals

Get all approval requests.

Example Request:

curl -X GET http://localhost:8080/api/approvals

Example Response:

[
  {
    "id": 1,
    "title": "Vacation Request",
    "description": "Requesting 5 days of vacation",
    "status": "PENDING",
    "comments": null,
    "createdAt": "2025-03-30T10:15:30",
    "updatedAt": "2025-03-30T10:15:30",
    "requester": {
      "id": 3,
      "name": "Alice Johnson"
    },
    "currentApprover": {
      "id": 2,
      "name": "Jane Smith"
    }
  }
]

POST /api/approvals

Create a new approval request.

Example Request:

curl -X POST "http://localhost:8080/api/approvals?requesterId=3" \
-H "Content-Type: application/json" \
-d '{
  "title": "Equipment Purchase",
  "description": "Need a new laptop for development work"
}'

Example Response:

{
  "id": 2,
  "title": "Equipment Purchase",
  "description": "Need a new laptop for development work",
  "status": "PENDING",
  "comments": null,
  "createdAt": "2025-03-30T11:20:15",
  "updatedAt": "2025-03-30T11:20:15",
  "requester": {
    "id": 3,
    "name": "Alice Johnson"
  },
  "currentApprover": {
    "id": 2,
    "name": "Jane Smith"
  }
}

POST /api/approvals/{id}/approve

Approve a request.

Example Request:

curl -X POST http://localhost:8080/api/approvals/1/approve \
-H "Content-Type: application/json" \
-d '{
  "comments": "Approved. Enjoy your vacation!"
}'

Example Response:

{
  "id": 1,
  "title": "Vacation Request",
  "description": "Requesting 5 days of vacation",
  "status": "APPROVED",
  "comments": "Approved. Enjoy your vacation!",
  "createdAt": "2025-03-30T10:15:30",
  "updatedAt": "2025-03-30T12:05:45",
  "requester": {
    "id": 3,
    "name": "Alice Johnson"
  },
  "currentApprover": {
    "id": 2,
    "name": "Jane Smith"
  }
}
